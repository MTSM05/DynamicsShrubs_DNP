# DynamicsShrubs_DNP
Data and RScripts linked to the manuscript on Distance from the climatic niche optimum explains species abundance shifts under progressive aridification in Mediterranean shrublands of Doñana National Park

Last update 2025/09/16

T. Sánchez-Mejía


# DATA
- coverniche_data.RData -> R data file containing species datasets, including both a long-term (1950–2022) climatic dataset and a short-term (2007–2022) dataset with climatic and shrub cover data.
Both datasets include centroid distance per species and year; the short-term dataset additionally includes shrub cover per species and year.

# CODE
- DNPshrubs_Statistical analysis_20260315:  Code with all statistical analysis included in the main text. 

# FIGURES
- Figure2.RCDevol.pdf: Temporal trends in centroid distance (CD) (2007-2022; 1950-2022) and community-weighted centroid distance (CWCD) (2007-2022).
- Figure3.Shrubevol.pdf: Temporal trend in total shrub cover and species cover (2007-2022).
- Figure4.ShrubRCD.pdf: Relation net change in cover (2007-2022) and temporal trend in CD and CWCD.
- Figure6.NMDS.pdf: NMDS showinng compositional changes over time (2007-2022).
